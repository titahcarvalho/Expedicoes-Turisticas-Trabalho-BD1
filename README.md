# Sistema de Planejamento e Gerenciamento de Viagens e Roteiros Turísticos

## Sobre o projeto

Este projeto está sendo desenvolvido para a disciplina de Banco de Dados I, do curso de Sistemas de Informação da Universidade Federal de Ouro Preto (UFOP).

O objetivo é desenvolver um sistema que permita aos viajantes planejar e gerenciar suas viagens de maneira organizada, reunindo informações sobre destinos turísticos, passeios, hospedagens, transportes, despesas e roteiros diários.

O sistema busca facilitar o acompanhamento do planejamento turístico, permitindo cadastrar e consultar informações relacionadas às viagens, além de acompanhar os gastos em relação ao orçamento planejado.

O desenvolvimento contempla a modelagem conceitual por meio do Diagrama Entidade-Relacionamento (DER), o mapeamento para o modelo relacional, a implementação do banco de dados e a construção de uma aplicação com interface gráfica.

## Funcionalidades previstas (RF01 a RF07)

O sistema está sendo desenvolvido para oferecer as seguintes funcionalidades:

- **Gerenciamento de viagens:** cadastrar e consultar viagens, incluindo datas de início e término.
- **Gerenciamento de destinos:** cadastrar os destinos associados a cada viagem.
- **Gerenciamento de passeios:** registrar atividades turísticas, suas datas e horários.
- **Gerenciamento de hospedagens:** armazenar informações sobre hotéis, pousadas e outras acomodações.
- **Gerenciamento de transportes:** registrar deslocamentos, incluindo origem, destino, datas e horários.
- **Controle de despesas:** registrar gastos e acompanhar o orçamento planejado.
- **Organização de roteiros diários:** planejar as atividades previstas para cada dia da viagem.

## Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias e ferramentas:

- **PostgreSQL:** sistema gerenciador de banco de dados relacional.
- **Python:** linguagem de programação utilizada no desenvolvimento da aplicação.
- **Tkinter:** biblioteca para construção da interface gráfica.
- **Psycopg:** driver para comunicação entre Python e PostgreSQL.
- **DBeaver:** ferramenta para administração e consulta ao banco de dados.
- **Visual Studio Code:** ambiente de desenvolvimento.
- **draw.io (diagrams.net):** ferramenta para elaboração do Diagrama Entidade-Relacionamento (DER).
- **Git e GitHub:** controle de versões e hospedagem do código-fonte.

As ferramentas estão sendo utilizadas ao longo das etapas de modelagem, implementação e desenvolvimento da aplicação.
